The long-tail trap

Confidence works, until the problems get hard.

The idea

Not how confident. When.

Late confidence means the reasoning converged. Early confidence means the model committed before exploring.

A model that sees several routes splits its probability between them, so good reasoning starts uncertain and ends certain. That is consilience: a conclusion is trustworthy when several lines of reasoning arrive at it.

The score
S = Cfinal − α·Cinitial

Reward certainty earned at the end. Penalise certainty claimed at the start. Keep the highest-scoring trace.

ctToken confidence: −mean of the top-5 log-probs. High when the alternatives are ruled out.
CinitialMean ct over the first 20% of reasoning, after skipping 5%.
CfinalMean ct over the last 20% of reasoning.
αPenalty weight. Default 3; anything in 2–5 works.

Use it

A few lines on top of the logprobs you already have.

Needs only the top-5 log-probs of the reasoning tokens. Scoring is free.

import numpy as np

def consilience(topk_logprobs, alpha=3.0, window=0.2, skip=0.05):
    # topk_logprobs: [L, K] top-K log-probs of the reasoning tokens (K = 5)
    c = -np.asarray(topk_logprobs).mean(axis=1)    # token confidence
    L = len(c)
    p, w = int(skip * L), max(1, int(window * L))
    return c[-w:].mean() - alpha * c[p:p + w].mean()

# best-of-n: score each sample's reasoning, keep the argmax
best = max(samples, key=lambda s: consilience(s.reasoning_logprobs))
  • α3 (2–5 is safe)
  • Window20–30%, or 2,048 tokens
  • SkipFirst 5%
  • ScopeReasoning tokens only (before </think> or GPT-OSS's final channel)
  • AgentsScore only high-value steps. SWE-bench: 18 h vs 8 h, not 32×.

The problem (LiveCodeBench #3, pass@1 = 0.03)

Given an undirected tree rooted at node 0 with n nodes, where each node has a value nums[i] and each edge has an integer length. A special path is a downward path (ancestor → descendant) in which all node values are distinct. Return [max_length, min_nodes]: the length of the longest special path, and the minimum number of nodes among all such longest paths. (n ≤ 5·10⁴, nums[i] ≤ 5·10⁴.)
